# Support

## Questions and usage help

Open a GitHub issue with the `question` label:

https://github.com/lixiang117423/biopytools/issues

Include the command, version (`biopytools --version`), Python version, operating
system, and the relevant part of `99_logs/` or the terminal output.

## Bug reports

Use the bug-report issue template. A minimal reproducible example is strongly
preferred. Remove private data and credentials before posting.

## Feature requests

Use the feature-request issue template and describe the analysis problem rather
than only the proposed implementation.

## Security reports

Do not open a public issue for credentials, code execution vulnerabilities, or
private data exposure. Email the maintainer at lixiang117423@gmail.com.

## Support scope

Maintainers provide best-effort support for the current release. Support for
third-party programs is limited by the documentation and installation options
provided by those upstream projects.
