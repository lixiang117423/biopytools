# JOSS manuscript

`paper.md` is the Journal of Open Source Software (JOSS) submission manuscript.
`paper.bib` contains the cited references.

The draft PDF is built by `.github/workflows/joss-paper.yml` using the official
Open Journals draft action. The generated `paper.pdf` is uploaded as a workflow
artifact and is not committed.

Before submission, follow `../JOSS_CHECKLIST.md`.
